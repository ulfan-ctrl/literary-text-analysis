Exploring Vocabulary Patterns in English Literary Texts
Project Overview

This project explores vocabulary patterns in two English short stories using Python. The main aim is to identify frequently used words and compare vocabulary across the texts.

Texts Analysed
* "The Gift of the Magi" by O. Henry
* "The Story of an Hour" by Kate Chopin

Methods
The analysis was carried out in Google Colab using Python.

The main steps included:
1. Loading and preparing the literary texts.
2. Counting words and identifying unique words.
3. Removing punctuation and common stopwords.
4. Identifying the ten most frequent words.
5. Creating bar charts to visualize word frequencies.
6. Comparing selected words using relative frequencies per 1,000 words.

Results

The results show differences in vocabulary between the two stories.
In "The Gift of the Magi", the word “hair” appears frequently, reflecting its importance in the story.
In "The Story of an Hour", words such as “free”, “life”, and “door” have higher relative frequencies.
These patterns may be connected to the themes of love, sacrifice, freedom, and independence.

Tools and Libraries Used
* Python
* Google Colab
* Matplotlib
* NumPy
* Scikit-learn
* Python libraries: re and collections
* Github

Conclusion
This project demonstrates how Python can be used to explore vocabulary patterns in literary texts. Word-frequency analysis can support literary interpretation, but the results should also be considered alongside close reading.
